# Vansh Rana Portfolio — Static Website

This is a frontend-only conversion of the supplied portfolio design. It uses HTML, CSS, JavaScript, Bootstrap, and Font Awesome. There is no server or build step; `index.html` is ready for GitHub Pages.

## Before publishing

- Replace `your-username` and `your-email@example.com` in `index.html` and `js/site.js` with your real profile and email details.
- Replace the sample project titles, descriptions, images, and GitHub/demo links with your own work.
- Update your college name and graduation details in the Education section.
- Add your resume PDF to this folder named `resume.pdf`, or change the resume links to the filename you choose.
- Edit skill names and percentages so they reflect your current experience.

The contact form is intentionally static. It opens the visitor's email app with their message filled in; it does not store or send messages through a server.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Upload the contents of this folder to the repository's top level. Keep the `css`, `js`, and `images` folders alongside `index.html`.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, the site will be available at `https://your-username.github.io/repository-name/`.

This page also works locally by opening `index.html` in a browser. Bootstrap, icons, and the selected font are loaded from public CDNs.
